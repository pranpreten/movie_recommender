# 영화 취향 검색

영화의 장르, 키워드, 소개글을 TF-IDF 벡터로 변환해 비슷한 영화를 추천하는 데스크톱 프로그램입니다. Python 표준 라이브러리만 사용합니다.

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe movie_browser.py
```

가상환경이 이미 있으면 마지막 명령만 실행하면 됩니다. 활성화된 가상환경에서는 `python movie_browser.py`로 실행합니다. 추가 패키지가 없어 requirements.txt는 비어 있습니다. Linux에서는 배포판의 tkinter 패키지가 필요할 수 있습니다.

## 기능

- 목록의 영화를 선택하거나 두 번 클릭해 유사 영화 5편 추천
- `우주 탐사 가족`, `범죄 추리 반전` 같은 문구로 내용 검색
- 장르 필터와 추천 근거 표현 표시
- 영화 CSV 불러오기 및 추천 결과 CSV 저장

검색창의 입력은 왼쪽 목록에서 제목을 필터링합니다. 제목에 없는 문구로 검색해서 목록이 비어도 `내용으로 추천` 버튼으로 내용 검색을 실행할 수 있습니다.

## 계산 방법

단어와 단어 내부의 2글자 조각을 함께 사용합니다. 형태가 조금 다른 한국어 표현의 부분 일치를 허용하기 위한 단순한 방법입니다. 장르는 3회, 키워드는 2회, 소개글은 1회 반영하며 TF-IDF 가중치를 L2 정규화한 뒤 내적으로 코사인 유사도를 구합니다.

유사도는 텍스트의 공통 표현 정도이며 사용자가 영화를 좋아할 확률이나 모델 정확도가 아닙니다. 사용자 평점 학습이나 협업 필터링은 사용하지 않습니다.

## 데이터

`catalog.csv`에는 영화 40편의 기본 정보와 이 프로젝트에서 직접 작성한 짧은 소개·키워드가 들어 있습니다. 외부 영화 API나 크롤링 결과를 사용하지 않은 데모 카탈로그입니다. 영화 소개는 전체 줄거리를 대체하지 않으며 출시 서비스용 검증 데이터가 아닙니다.

사용자 CSV는 UTF-8 형식으로 다음 열을 포함해야 합니다.

```csv
title,year,genres,keywords,description
예제 영화,2024,SF|모험,우주 탐사 생존,우주에서 구조를 기다리는 탐사대의 이야기
```

장르 구분자는 `|`이고 영화가 두 편 이상 필요합니다. 같은 제목과 연도의 중복 행은 한 번만 사용합니다.

```powershell
.\.venv\Scripts\python.exe recommendation_cases.py -v
```
